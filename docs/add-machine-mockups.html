Add a machine

Run setup on the Mac or Linux machine you want to add.

1. Before you start

git, curl and Python 3

Install these on the new machine first. The installer checks for git and Python 3; curl is needed to download it.

A coding harness, signed in

Claude Code, Codex, OpenCode or Copilot. Run it once in that terminal to make sure it works before starting bots.

Access to this board

The machine must be able to reach your board address. Join the same tailnet if your board is private to Tailscale.

For GitHub work, also install gh and sign in with gh auth login.

2. Open a terminal on that machine and run

Terminal / board address and your handle filled in automatically
Open this preview on your board while signed in to get your ready-to-run command.

Downloads the bot utilities, saves the board connection, and installs the background keeper. No sudo needed. Dependencies and coding harnesses are not installed by this command.

3. Your machine appears here

Once the keeper reports in, start a worker from the machine's card.

Nothing to edit: uses the current board address and your signed-in board handle. Use a board address reachable from the new machine, not localhost. Invite-protected boards also need their invite code.
